# MY WORLD

Карта посещённых стран и городов, 3D-глобус и планировщик поездок. Работает в браузере и ставится на iPhone как приложение (PWA).

Адрес: **https://tsaga7.github.io/myworld/**. Публикация — GitHub Actions → GitHub Pages при каждом пуше в `main`.

## Запуск

```
npm install
npm run dev              # http://localhost:5174
npm run check            # типы, линтер, тесты
npm run build            # сборка в dist/
```

## Устройство

```
src/domain   чистая логика: модель (Zod), статистика, перенос поездки на карту, поиск, даты
src/data     IndexedDB (Dexie, база "myworld"), все записи, резервная копия JSON
src/geo      справочники: страны (в бандле), города и границы (public/data, загружаются один раз)
src/screens  Планета (MapLibre: карта и глобус), Страны, Путешествия, Настройки
src/ui       общие компоненты, иконки, поиск мест, работа с файлами
scripts      генерация геоданных из Natural Earth и топографического фона
```

- **Карта и глобус** — одна WebGL-сцена MapLibre GL с проекциями Mercator и globe, поэтому отметки в обоих видах одни и те же. Без WebGL или в «Упрощённом режиме» работает SVG-карта (d3-geo) с тем же набором действий.
- **Данные пользователя** разделены по таблицам: `cities` (снимки городов), `visits` (факты посещения), `plans` (запланированные места), `trips`, `stops`, `transport`, `stays`, `bookings`, `notes`, `attachments` + `blobs` (файлы отдельно от метаданных), `tasks`, `meta`. У посещений и планов одна запись на место (`key` уникален), поэтому повторные действия ничего не дублируют.
- **Деньги**: цены в ₽, $ или €; сумма поездки пересчитывается по курсу ЦБ (обновляется в настройках или вводится вручную).
- **Даты** — строки `YYYY-MM-DD`, время — `HH:mm` по месту, без пересчёта часовых поясов.
- **Офлайн**: service worker кэширует приложение, границы стран, справочник городов и флаги. Подробная подложка OpenFreeMap подключается только при доступном интернете.

## Геоданные

`npm run geodata` пересобирает `src/data/countries.json`, `public/data/*` и флаги. Источники: Natural Earth (общественное достояние), flag-icons (MIT). Результат лежит в репозитории, сборке сеть не нужна.
